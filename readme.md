# Farmer First Marketplace

A simple web application for the Farmer First Marketplace built using HTML, CSS, and JavaScript.

---

# How to Run the Project

## Prerequisites

Install the **Live Server** extension in Visual Studio Code.

- **Name:** Live Server
- **ID:** `ritwickdey.LiveServer`
- **Version:** 5.7.10
- **Publisher:** Ritwick Dey
- **VS Marketplace:** https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer

---

## Steps to Run

### Admin Module

1. Open the project in **Visual Studio Code**.
2. Open **`loadAdminModule.html`**.
3. Click **Go Live** (bottom-right corner) or right-click the file and select **Open with Live Server**.
4. The **Admin Dashboard** will open in your browser.

### Farmer Module

1. Open **`loadFarmerModule.html`**.
2. Click **Go Live** (bottom-right corner) or right-click the file and select **Open with Live Server**.
3. The **Farmer Module** will open in your browser.
